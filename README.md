# biopelayo.github.io

Personal website of Pelayo González de Lena (biopelayo): plant epigenomics, quantitative histone PTM proteomics, cancer bioinformatics, and reproducible pipelines.

v2 (August 2026): single-page CV-style site, hand-written HTML/CSS/JS with no frameworks and no build step. Dual dark/light theme, bilingual EN/ES (client-side dictionary), print stylesheet, and the nucleosome particle canvas as its signature background.
